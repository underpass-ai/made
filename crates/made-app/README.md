# made-app

Application use cases for [MADE](https://github.com/underpass-ai/made).

Coordinates commands and queries through `made-core` ports. Use cases hold dependencies behind traits; domain aggregates validate state changes. The same use cases run under the service and embedded compositions. YAML encoding, network clients and concrete stores belong in adapters.
