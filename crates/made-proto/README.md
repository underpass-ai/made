# made-proto

Service protobuf bindings for [MADE](https://github.com/underpass-ai/made).

Builds bindings from the canonical `underpass.made.v1` service contract. Change the schema together with adapters, parity expectations and compatibility tests. A protobuf message shape is a boundary DTO, not the domain model.
